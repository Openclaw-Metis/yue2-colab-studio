## 非技術規格文件

專案名稱：YuE2 Colab 寫歌工作室｜日期：2026-11-11

### 這份規格是寫給誰看的

寫給想用 YuE2 做歌、但不寫程式的人，也寫給要決定「這個工具該不該這樣做」的人。讀完之後，你會知道它能做什麼、怎麼操作、會看到什麼畫面、有哪些限制。

本文件依據幾個尚未逐項確認的前提：第一版只做「寫歌」與「改樂譜」，不做翻唱；歌曲預設存在 Colab 的暫時空間，可以選擇改存到你的 Google 雲端硬碟；一次只做一首歌。

### 這個工具能做什麼

你輸入「曲風描述」和「歌詞」，它會幫你做出一首有人聲、有伴奏的完整歌曲，音質是一般線上音樂平台等級的立體聲。

它和一般的 AI 做歌工具最大的不同，是做歌之前會先寫出一份樂譜（旋律與和弦）。你可以先看這份樂譜、動手改幾個音，再讓它照著你改過的版本唱出來。

做好的每一首歌都會收進「歌曲庫」。你可以回頭播放、改名字、寫備註、刪除，或是拿某一首當起點再做一個新版本。

這個工具在 Google Colab 上執行，你不需要自己有高階顯示卡，但需要在 Colab 選用名為「L4」的付費運算資源。

### 你會怎麼使用它

**第一次啟動（大約只需要按三次執行）**

1. 用瀏覽器打開專案提供的 Colab 筆記本。
2. 在上方選單「執行階段」→「變更執行階段類型」，選擇 L4 GPU。
3. 執行第一格。它會檢查你選的運算資源對不對，然後自動安裝需要的東西，要等幾分鐘。看到「環境檢查通過」就完成了。
4. 執行第二格。它會問你要不要把歌曲存到 Google 雲端硬碟，並顯示一組這次專用的通行碼。
5. 執行第三格。畫面會出現一個連結，點開後輸入通行碼，就會看到寫歌的畫面。

**做一首歌**

1. 在「曲風」欄寫下你想要的感覺，例如：國語、溫暖的鋼琴流行、女聲、木吉他與輕鼓、88 BPM。
2. 在「歌詞」欄貼上歌詞，用 `[Verse]`、`[Chorus]` 這樣的標記分段。
3. 按「生成歌曲」。
4. 畫面最上方會告訴你現在做到哪一步。第一次做歌時，還要先下載作曲引擎，會多等一段時間。
5. 完成後畫面會自動跳到「成品」，你可以直接播放和下載。

**想先看樂譜、改樂譜**

1. 在按鈕旁勾選「先看樂譜再生成」，按鈕會變成「產生樂譜」。
2. 樂譜寫好後，畫面跳到「樂譜」分頁，內容是一種叫 ABC 的文字樂譜。
3. 你可以直接修改文字，或上傳自己準備好的樂譜檔。上傳後內容會先顯示在編輯框，讓你確認是不是選對檔案。
4. 按「用這份樂譜生成」，它就會照這份樂譜做歌。

**再做一版**

在成品頁按「以此為基礎再做一版」，原本的曲風和歌詞會回到表單，改幾個字再生成即可。

**結束使用**

回到 Colab，在「執行階段」選擇「中斷並刪除執行階段」。不這樣做的話，運算額度會繼續被扣。

### 你會看到哪些主要畫面

**最上方的狀態列（永遠都在）**
顯示現在的狀況：「就緒」、「作曲規劃中」、「譜寫內容中」、「聲音合成中」、「音訊解碼中」、「保存中」。做歌時右邊會有「取消」按鈕和已經過的時間。

**1 寫歌**
兩個輸入框（曲風、歌詞）、一個勾選框（先看樂譜再生成）、一顆主要按鈕。下方有一個預設收起來的「進階設定」，裡面可以選樂譜的規劃方式、指定隨機種子、調整文字引導強度。多數時候不需要打開它。

**2 樂譜**
一個可以編輯的樂譜文字框，上方標示這份樂譜是「引擎規劃」「你修改過」還是「你上傳的」。下方是「用這份樂譜生成」按鈕。還沒有樂譜時，這一頁只會顯示一行說明，告訴你怎麼產生樂譜。

**3 成品**
播放器、「下載音訊」、「下載完整產物」（包含樂譜和所有設定的壓縮檔）、可展開的樂譜全文，以及「以此為基礎再做一版」。

**歌曲庫**
一張清單列出所有做過的歌：名稱、時間、長度。點選其中一首，可以播放、改名稱、寫備註、刪除、載回表單、下載。

**環境資訊（頁面最下方，預設收起來）**
顯示目前使用的運算資源和版本。出問題時這裡會自動打開，並提供「複製診斷資訊」讓你回報問題。

### 畫面風格與色彩

整體是明亮、乾淨的工具風格，重點是讓你在等待的時候感到安心，不做花俏的裝飾。

- **深藍色**：只用在每個畫面最重要的那一顆按鈕，以及你目前所在的分頁。
- **淺藍灰色**：狀態列和收合區塊的底色，用來把不同區域分開。
- **琥珀色**：表示「正在進行」或「請留意」，例如進度條和「歌曲可能提前結束」的提醒。
- **紅色**：只在出錯時出現。
- 文字是深灰色配白色背景，確保清楚好讀。

### 操作流程

| 你做的事 | 畫面的回應 |
|---|---|
| 打開連結並輸入通行碼 | 看到「1 寫歌」，如果上次有沒寫完的內容，會自動填回來 |
| 填好曲風，還沒填歌詞 | 主要按鈕可以按；歌詞留空會嘗試做純音樂，但不保證完全沒有人聲 |
| 曲風是空的 | 主要按鈕不能按，下方顯示「請先填寫曲風」 |
| 按「生成歌曲」 | 按鈕變成不能按，狀態列開始顯示進度，出現「取消」 |
| 做歌途中重新整理網頁 | 歌會繼續做，狀態列接著顯示目前進度 |
| 做歌途中按「取消」 | 半分鐘內停止，你填的內容都還在 |
| 歌做好了 | 自動跳到「3 成品」，並短暫顯示「歌曲完成」 |
| 按「以此為基礎再做一版」 | 回到「1 寫歌」，內容已填好 |
| 按「重新開始」 | 先問你是否確定，確定後清空表單與樂譜；已完成的歌不受影響 |
| 在歌曲庫刪除一首歌 | 先問你是否確定，確定後這首歌永久移除 |

### 限制與注意事項

- **一定要選 L4。** 免費的 T4 無法使用，工具會在第一步就提醒你並停止。L4 需要 Colab 的付費運算額度，而且 Colab 不保證每次都分配得到。
- **一次只能做一首歌。** 前一首還沒做完時不能開始下一首。
- **需要等待。** 做一首歌需要數分鐘。確切時間要等實際量測後才會寫進說明文件，目前不做任何承諾。
- **沒有「歌曲長度」「調性」的獨立設定。** 速度與風格請寫在曲風描述裡；旋律、和弦與調性要在樂譜裡調整。
- **不能指定特定歌手的聲音。** 曲風描述只能引導歌聲的感覺，不保證是某個特定的人。
- **樂譜只支援兩個聲部**（人聲旋律與樂器旋律）。多加的聲部不會變成可以單獨控制的樂器。
- **改樂譜會重做整首歌**，不是只修改某一小段。沒改到的地方聽起來也可能不同。
- **歌詞留空不保證沒有人聲**，請聽過再決定要不要使用。
- **結果有隨機性。** 同樣的輸入可能做出不同的歌，品質也會有高低，建議多做幾版挑選。
- **連結不要隨意分享。** 拿到連結和通行碼的人可以使用你的運算額度。
- **第一版不包含**：翻唱既有歌曲、MP3 下載、樂譜的五線譜顯示、多人共用。
- **使用條款。** 作曲引擎由 M-A-P 團隊提供：個人創作者可以自由使用成品並從中獲利；學術研究限非商業用途；公司商業使用需另外向原團隊取得授權。

### 成功完成後會得到什麼

每做完一首歌，你會得到：

- 一個可以直接播放的高音質音訊檔（FLAC 格式）。
- 這首歌的樂譜（ABC 文字格式），選擇「不規劃」時沒有。
- 一份完整的紀錄，包含你當時填的曲風、歌詞、所有設定，以及做這首歌花了多少時間。
- 以上全部可以打包成一個壓縮檔下載。

這些內容都會留在歌曲庫，日後可以拿來重做或比較。

### 常見問題與錯誤提示

| 你遇到的狀況 | 可能原因 | 怎麼處理 |
|---|---|---|
| 第一格顯示「不是 L4」 | 執行階段選到別的類型 | 變更執行階段類型為 L4 後重新執行 |
| Colab 說無法連線到 L4 | 當下沒有可分配的 L4，或額度用完 | 稍後再試，或確認運算額度 |
| 第一格安裝失敗 | Colab 的預設環境改版 | 選「中斷並刪除執行階段」後重來；仍失敗請附上畫面訊息回報 |
| 連結打不開 | 連結已失效，或第三格已停止 | 回 Colab 確認第三格仍在執行，必要時重新執行第二、三格 |
| 忘記通行碼 | | 回到 Colab 第二格的輸出查看 |
| 狀態列很久沒有變化 | 第一次使用正在下載作曲引擎 | 耐心等待；超過 45 分鐘會自動停止並提示 |
| 出現「顯示卡記憶體不足」 | 歌詞太長，或前一次留下的占用 | 縮短歌詞；或在環境資訊按「釋放引擎」再試 |
| 歌曲在中途就結束 | 長度達到上限 | 縮短歌詞，或分成兩首 |
| 重開 Colab 後歌曲庫是空的 | 上次沒有選擇存到 Google 雲端硬碟 | 下次在第二格選擇雲端硬碟；這次的歌無法找回 |
| 改了樂譜後出現格式錯誤 | 樂譜寫法不符合規則 | 按「還原為引擎規劃的樂譜」後重新修改 |
| 聽到的歌和預期差很多 | 結果本來就有隨機性 | 換一個隨機種子或調整曲風描述再做一版 |
